## Findings to know before the demo

1. Sector notes text is wrong about the source. The LLM-written `sector_notes` say "news-based estimate (tkg_lite)" in india_diversified and concentrated_it, and "(source: tkg)" in energy_and_autos. The cause is the synthesis prompt (`flow/synthesis.py`, rule on `tkg_lite`). The chip and `meta` are correct. Not changed (no code changes allowed).
2. The TKG path evidence is not in the API response or the UI. It is only in the saved `*.state.json` under `stage1_sector[...].evidence.paths`. The UI shows the sentiment recheck headlines.
3. The same crude headline can appear as both BENEFITS and HURTS for oil_gas ("India's crude basket price tops $120..." is -0.47 in a +0.57 sector). Avoid showing that sector's path list.
4. Neutral sectors (healthcare, power) are shown as "sector news neutral" and excluded from fusion.
5. Sector signal is per sector, so all four IT holdings and all three oil names carry identical scores.
